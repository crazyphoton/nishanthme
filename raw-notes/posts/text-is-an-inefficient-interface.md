# Text is an inefficient interface

## What I want to say

- Text is a flexible but inefficient way to communicate context to AI.
- Build cheap, disposable, custom interfaces for the specific work in front of you.
- Chat is general-purpose, and general-purpose is wrong when the problem is "what should I pay attention to?"

## Raw notes

- Automated Value Generation = humans communicating context to the AI.
- Impatience: half-baked instructions, model fills gaps, sometimes misses.
- Spec-driven dev: spec grew to fifty pages; describing changes by prose got annoying.
- Fix: browser + highlight + inline comments feeding a task system the agent watched.
- Since then: Kanban board with custom fields, dashboards, charts, voice summaries.
- Interfaces are cheap now; build one for a session and throw it away.
- Turtles all the way: layers of interpretation, loss per translation, interfaces drift.
